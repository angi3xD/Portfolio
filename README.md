# ✦ Angela.dev — Portfolio

Portfolio personale realizzato durante il corso **Full Stack Development e Agenti AI** di start2impact University.
Un sito in stile **Y2K / Retro-Chic & Soft Glam**, che unisce la nostalgia dei primi anni 2000 alla pulizia del design editoriale contemporaneo.

🌐 **Sito online:** [angi3xd.github.io/Portfolio](https://angi3xd.github.io/Portfolio/)

## Pagine

- **Home**: presentazione, sezione progetti con galleria di screenshot e link al codice
- **Il mio CV**: curriculum in HTML con competenze, formazione, esperienze e attestati, scaricabile in PDF
- **Contattami**: form di contatto funzionante con invio email tramite EmailJS

## Tecnologie

- **HTML5**: struttura semantica (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **SASS (SCSS)**: variabili, nidificazione e file separati per variabili e reset
- **Bootstrap 5**: Modal e Carousel per le gallerie, Collapse per il menu hamburger
- **Flexbox e CSS Grid**: layout di navbar, hero, card progetti e CV
- **EmailJS**: invio reale dei messaggi dal form contatti

## Caratteristiche

- Design responsive per smartphone, tablet e desktop
- Navbar sticky, che su mobile diventa un menu hamburger
- Galleria progetti con screenshot desktop e mobile
- Marquee animata realizzata solo con CSS (`@keyframes`)
- Favicon personalizzata
- CV scaricabile in PDF
